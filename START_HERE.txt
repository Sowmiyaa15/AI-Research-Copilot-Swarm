================================================================================
                    INSTALLATION STEPS
================================================================================

STEP 1: INSTALL DEPENDENCIES
-----------------------------
Open terminal/command prompt in this folder:

    pip install -r requirements.txt

Wait for: "Successfully installed Flask-3.0.0 flask-cors-4.0.0 requests-2.31.0"


STEP 2: START BACKEND SERVER
-----------------------------
Keep terminal open and run:

    cd backend
    python app.py

You should see:
    "Server running on http://localhost:5000"

⚠️  IMPORTANT: KEEP THIS TERMINAL WINDOW OPEN!


STEP 3: OPEN FRONTEND
----------------------
Open a NEW terminal or simply:

    Open: frontend/index.html in your web browser

OR use the launcher scripts:
    Windows: Double-click OPEN_FRONTEND.bat
    Linux/Mac: Run ./OPEN_FRONTEND.sh


STEP 4: ENTER RESEARCH TOPIC
-----------------------------
In the web interface:

1. Type your query in the input box
   Examples:
   - "machine learning in healthcare"
   - "deep learning computer vision"
   - "natural language processing transformers"

2. Click "🔍 Analyze Research"

3. Wait 10-30 seconds


STEP 5: VIEW ALL AGENT OUTPUTS
-------------------------------
Results appear in 6 sections:

📊 Executive Summary
   - Total papers analyzed
   - Methods identified
   - Gaps found
   - Ideas generated

📚 Section 1: Retrieved Papers
   - Top 5 papers from arXiv
   - Titles, authors, abstracts
   - Links to full papers

🔬 Section 2: Knowledge Extraction
   - Methods used in each paper
   - Key findings
   - Problem domains

⚖️ Section 3: Method Comparison
   - List of methods
   - Strengths of each method
   - Weaknesses of each method
   - Best performing method

✅ Section 4: Claim Validation
   - Confidence score
   - Consistent claims across papers
   - Conflicting claims
   - Evidence counts

🔍 Section 5: Research Gaps
   - Identified opportunities
   - Categorized by type:
     * Methodological gaps
     * Data-related gaps
     * Scalability issues
     * Evaluation needs

💡 Section 6: Research Ideas
   - Actionable research proposals
   - Proposed methods
   - Impact assessment
   - Feasibility ratings

================================================================================
                    TROUBLESHOOTING
================================================================================

PROBLEM: "Module not found"
SOLUTION: pip install -r requirements.txt

PROBLEM: "Port 5000 already in use"
SOLUTION: Edit backend/app.py, change port to 5001

PROBLEM: CORS errors in browser
SOLUTION: pip install flask-cors, restart backend

PROBLEM: No papers retrieved
SOLUTION: Check internet connection, try different query

PROBLEM: Frontend won't load
SOLUTION: Check if backend is running on localhost:5000

================================================================================
